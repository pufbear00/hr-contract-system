# HR 合同系统

此目录是单独的本地代码副本，不连接原系统、不附带 Git 历史，也没有员工、公司、账号、工资记录、原合同模板、上传附件或生成文档。保留员工/公司管理、模板上传、模板集合及本地合同生成的界面和代码。请只输入虚构资料，不要把原系统备份导入这里。

## 与原版的隔离

- 基于已下载源码 `1e7ad8ca8c6080a02c58d3a8d51d2d3d4182f71e`，未合并旧运行目录的未提交修改。
- 移除原飞书连接器及其内部部门映射；同步 API 固定返回 503，无法用环境变量重新打开。
- 备份恢复入口同样返回 503，防止一键导入原系统真实资料；可手动创建虚构记录、上传自己制作的虚构模板。
- 所有数据固定保存于本副本 `backend/local_runtime/`；不读取 `.env`、旧数据库、原上传目录或继承的 `HR_` 配置。
- 首次启动只建空表；必须自行创建新演示账号，不提供原账号、默认密码或固定签名密钥。签名密钥每次后端启动重新生成，重启后需重新登录。
- 不带任何真实合同模板；可自行制作虚构的 DOCX 模板来演示。原版缺失的员工请求/响应 schema 已补齐。
- 自动补全/补偿计算是保留的演示代码，不应据此处理真实合同、薪资或法律事务。

## 本地启动

需要 Python 3.12、Node.js 及 npm。仅安装依赖时需要网络；应用运行不访问飞书或其他业务服务。不要在原项目环境中运行。终端进入本目录，分别启动前后端：

```sh
cd backend
python3 -m venv .venv
.venv/bin/python -m pip install --only-binary=:all: -r requirements.txt
.venv/bin/python init_local.py --username demo-user
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8313
```

另开终端，在本目录：

```sh
cd frontend
npm ci --ignore-scripts
npm run dev
```

浏览器手动打开 `http://127.0.0.1:5313`，输入刚设置的账号密码。没有预设员工和模板属于正常空状态。不要加 `--host 0.0.0.0`，不要将此版本直接部署到公网。
